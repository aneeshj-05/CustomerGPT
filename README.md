# supportGPT

A fine-tuned GPT model for customer support automation.

## Project Structure

```
supportGPT/
├── data/        # Raw and processed datasets
├── src/         # Training, inference, and utility scripts
├── adapters/    # LoRA / PEFT adapter weights
├── outputs/     # Model checkpoints and evaluation results
├── README.md
├── requirements.txt
└── .gitignore
```

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
